# Korikone

A local Windows desktop application for planning meals and reviewing grocery baskets.

Implementation is in progress. The prototype targets editable recipes, weekly planning, Finnish and English, two demo stores, and a real K-Ruoka integration. S-kaupat integration is developed separately. Checkout is always manual.

See [the prototype scope](docs/prototype-scope.md) and [implementation plan](docs/implementation-plan.md).
