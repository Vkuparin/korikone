## F21. Models running on the same machine

Accepted for later work on 10 October 2026; release unassigned. Offer local inference as an alternative to ChatGPT, selected explicitly in Settings AI and reflected in the compact composer control. Initial scope connects to an already installed local model runner over loopback; bundling a runtime, downloading models and remote self-hosted servers need separate scope decisions. Local inference does not make retailer searches/transfers offline. Keep ChatGPT as the existing default, and never silently send a failed local request to ChatGPT.

Reuse the same interpretation, candidate-resolution and edit schemas, validation, request caps, cancellation, preview/commit rules and transfer safeguards. Local models supply reasoning, never authoritative retailer products/prices. Runtime support and adequate FI/EN quality must be measured rather than assumed from a compatible HTTP API.
