F22.1 compatibility research remains in [Later](later.md), without a v0.8 release gate. Start with existing K site/client and worker fallback. Keep grocery quantities, old profiles/backups, stable edit identities and inference-provider separation. Each unsupported path must remain visible/manual; no automatic store change, live account access, checkout, payment or slot booking.
